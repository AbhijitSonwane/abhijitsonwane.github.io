# abhijitsonwane.github.io

Portfolio and resume of Abhijit Sonwane. Live at https://abhijitsonwane.github.io

## How to update the site

1. Open https://abhijitsonwane.github.io and click **Owner login** at the very bottom.
2. Log in with your ID and password. An **Edit site** button appears at the top.
3. Make your changes and press **Publish**. The live site updates in about a minute.

First time, or new GitHub key: click Owner login, then "Set up again", and paste a GitHub fine-grained key
that has Contents: Read and write for this repository only. The key is stored in `data/auth.json`,
encrypted with your ID and password.

Backup editor: https://app.pagescms.org (sign in with GitHub) also works with this repo.

## Where things live

- `index.html`, `assets/` : the page design and editor
- `data/*.json` : the content
- `media/images`, `media/docs` : uploaded photos and PDFs
